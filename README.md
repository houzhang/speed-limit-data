# Speed-limit data

SQLite speed-limit bundle for the personal Speed Limit HUD.

- Derived from OpenStreetMap via the Geofabrik Ireland and Northern Ireland extract.
- © OpenStreetMap contributors, licensed under the Open Database Licence (ODbL).
- Advisory only. Road signs always take precedence.
- Coverage: Dublin and the Wicklow Mountains (latitude 52.75–53.45 N, longitude
  −6.80 to −5.90 W). Missing explicit limits are stored as `NULL`; the app shows
  no limit rather than a default.
- The `data-latest` release holds `manifest.json` and `speedlimit.sqlite`.
